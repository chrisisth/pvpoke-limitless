This section documents the specialized tools in PvPoke that extend beyond core PvP battle simulation. These tools serve different use cases and operate independently from the main ranking and battle systems:

* **Tera Raid Counter Calculator** - Evaluates attackers against Pokémon Scarlet/Violet raid bosses with Tera type mechanics. See [6.1](/pvpoke/pvpoke/6.1-tera-raid-counter-calculator) for detailed documentation.
* **Articles and Community Day Guides** - Educational content system with interactive IV checklists for Community Day events. See [6.2](/pvpoke/pvpoke/6.2-articles-and-community-day-guides) for detailed documentation.
* **GameMaster Editor** - Advanced customization tool for modifying Pokémon stats, moves, and learnsets in custom simulations. See [6.3](/pvpoke/pvpoke/6.3-gamemaster-editor) for detailed documentation.

Each tool operates with its own data structures, UI patterns, and calculation logic, largely independent from the core PvP systems documented in [3](/pvpoke/pvpoke/3-core-battle-system) and [4](/pvpoke/pvpoke/4-rankings-system).

## System Characteristics

### Tera Raid Counter Calculator

The Tera Raid system is fully isolated with its own data format and battle mechanics:

| Aspect | Implementation |
| --- | --- |
| **Data Source** | Separate `tera/data/gamemaster.json` with Pokémon Scarlet/Violet stats |
| **Data Format** | Uses mainline game stats (hp, atk, def, spA, spD, spe) instead of GO stats |
| **Core Logic** | `TeraRanker.js` calculates offensive and defensive type effectiveness scores |
| **Unique Features** | Tera type system, trait effects (Thick Fat, Levitate, etc.) |
| **UI Namespace** | Isolated under `/tera/` path with custom styling |

The system does not share data or battle logic with the main PvP tools, operating as a standalone calculator.

Sources: [src/tera/data/gamemaster.json L1-L100](https://github.com/pvpoke/pvpoke/blob/59a4e0a2/src/tera/data/gamemaster.json#L1-L100)

### Articles and Community Day Guides

The articles system combines static content with interactive checklist functionality:

| Component | Purpose | Storage |
| --- | --- | --- |
| **articles.json** | Article metadata (id, title, path, tags, date) | Static file |
| **Article PHP Files** | Content pages with event details and IV recommendations | Server-rendered |
| **ArticleChecklist.js** | Interactive checklist for tracking catches and IV targets | localStorage |
| **Community Day Data** | Species-specific IV recommendations and evolution chains | JSON files |
| **Custom Styling** | Pokemon-themed colors and layouts per article | SCSS |

Checklist state persists in browser localStorage using keys like `cd-{articleId}`. The system integrates with core battle simulation to calculate CP values and IV ranks.

### GameMaster Editor

The GameMaster Editor is an advanced tool for creating custom game data:

| Feature | Description | Implementation |
| --- | --- | --- |
| **Custom Gamemasters** | User-defined Pokemon and move datasets | localStorage with custom keys |
| **Entry Management** | Add, edit, delete Pokemon and moves | CRUD interface with validation |
| **Validation System** | Enforce data integrity rules | `validations.json` + `GMEditorUtils.js` |
| **Changelog Generation** | Compare custom vs original data | Diff algorithm in `GMEditorInterface.js` |
| **Import/Export** | JSON-based data transfer | Textarea with copy functionality |

Custom gamemasters are stored separately from the default `gamemaster.json` and can be selected via the settings system documented in [7.3](/pvpoke/pvpoke/7.3-user-settings-and-themes).

## Performance Considerations

| Tool | Performance Impact | Mitigation Strategy |
| --- | --- | --- |
| **Tera Raid** | Generates 1000+ ranking permutations | Results displayed in batches of 50 [src/tera/js/TeraInterface.js L64-L66](https://github.com/pvpoke/pvpoke/blob/59a4e0a2/src/tera/js/TeraInterface.js#L64-L66) |
